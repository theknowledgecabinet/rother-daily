# Rother Daily

Local news for Bexhill, Battle, Rye and the Rother villages, morning and evening.

**Read it: https://theknowledgecabinet.github.io/rother-daily/**

- News feed (RSS): https://theknowledgecabinet.github.io/rother-daily/feed.xml (one per section under `/feeds/`)
- Evening audio briefing (podcast): https://theknowledgecabinet.github.io/rother-daily/podcast.xml

## How it is made

Rother Daily is written by AI, part of [The Knowledge Cabinet](https://theknowledgecabinet.github.io/).
A collector checks local sources through the day (Rother District Council, East Sussex County Council and the Bexhill and Battle town councils, the
MPs, police and highways updates, and local newspapers). Morning and evening
the newsroom reads what is new, checks the original pages, and writes short
summaries in its own words with links to every source. A story is never reported
twice: each one is compared by meaning with everything already published, and later
developments are added to the original story as updates.

The MP and councillors are looked up automatically every day, so the sources follow
whoever holds the role. The weather comes from Open-Meteo; the evening briefing is
read by a text-to-speech model (Kokoro); images are freely licensed from Wikimedia
Commons and credited on each page.

**Corrections:** if something is wrong, please open an issue in this repository.

This repository is rebuilt automatically after each edition and served by GitHub
Pages, so edits made here are overwritten. 30 stories so far.
